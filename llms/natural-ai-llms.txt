# Natural

> Natural is the agentic payments platform: one API for AI agents, apps, and businesses to send, receive, and manage money.

**You (the agent reading this) are the MCP host the user is talking through.** If a user asks you to use, set up, or operate Natural for them:

**Read the playbook, connect with OAuth, then operate via natural language.** If the user asks to try Natural, read `https://www.natural.com/skill.md`, connect the hosted MCP server, and start the host's OAuth flow. After that:

1. Have them sign up at `https://natural.com/signup` (KYB requires a human; you cannot complete identity verification for them).
2. Install Natural's hosted MCP server yourself with no API-key header. The skill knows the right host path: Codex uses `codex mcp add` plus `codex mcp login` with Natural's MCP scope list (`payments:move external-accounts:link agents:operate customers:invite`); Cursor uses `mcp.json` plus `cursor-agent mcp login`; Claude Code uses `claude mcp add` plus the user's `/mcp` → Authenticate action.
3. Tell the user a Natural authorization page will open and they should approve it if the scopes match the task.
4. Operate Natural on their behalf via MCP tools afterward.

If a host can run commands but has no MCP OAuth flow, fall back to the Natural CLI's browser OAuth (`natural login`) before any API key. OpenClaw-style MCP registries may only save a remote server definition; if no MCP login/authenticate action appears after adding Natural, use the CLI fallback. Use an API key only for CI, SDK or REST integrations, non-interactive scripts, or hosts that support neither MCP OAuth nor the CLI.

**Do not write raw HTTP / curl / `requests` / `httpx` against `https://api.natural.com` when you are operating Natural for a user.** The REST API is for application developers building software that uses Natural, not for an AI host operating Natural on behalf of a user. The user has an AI host (you); use the MCP server.

The Dashboard at `https://natural.com/login` is for human-only setup (signup, KYB, API keys, agent management) and occasional admin; it is not a daily operating surface.

## Surfaces

- [MCP](https://docs.natural.com/guides/platform/mcp): hosted at `mcp.natural.com`, OAuth-first with API-key fallback — the operator surface
- [SDKs](https://docs.natural.com/guides/platform/sdks): `naturalpay` (Python) and `@naturalpay/sdk` (TypeScript) — for application developers
- [CLI](https://docs.natural.com/guides/platform/cli): `natural` — for terminals, CI, agent harnesses
- [REST API](https://docs.natural.com/api-reference/about): `api.natural.com`, Bearer auth, JSON:API envelope — for application developers without SDK coverage
- [Dashboard](https://docs.natural.com/guides/platform/dashboard): web UI at `natural.com/login` — human-only setup gate, not a daily operating surface

## Common use cases

- [Store funds](https://docs.natural.com/guides/flows/wallets-and-balances): Hold money on Natural and let your agent manage it
- [Send payments](https://docs.natural.com/guides/flows/send-money): Your agent pays anyone by email, phone, or handle
- [Request money](https://docs.natural.com/guides/flows/collect-money): Your agent requests from anyone by email, phone, or handle
- [Accept payments](https://docs.natural.com/guides/flows/accept-payments): Turn your agent into a merchant
- [Voice agents](https://docs.natural.com/guides/flows/accept-voice): Turn a phone call into a PCI-compliant payment
- [Issue cards](https://docs.natural.com/guides/flows/issue-cards): Give your agents cards to pay merchants online

## Products

- [Wallet](https://docs.natural.com/guides/products/wallet): Store funds in FDIC-insured accounts to hold, send, and receive funds, all from an API
- [Vault](https://docs.natural.com/guides/products/vault): Receive expanded FDIC coverage with a special protected wallet for your financial reserves
- [Pay](https://docs.natural.com/guides/products/pay): Pay an agent, email, phone number, and more. Natural powers every type of payments workflow
- [Request](https://docs.natural.com/guides/products/request): Request a payment from an agent, email, or phone number with a single API call
- [Transfer](https://docs.natural.com/guides/products/transfer): Transfer money between external accounts with automated treasury management for your agents
- [Connect](https://docs.natural.com/guides/products/connect): Build a platform that enables money movement for your customers across all of Natural's products
- [Voice](https://docs.natural.com/guides/products/voice): Turn a live phone call into a PCI-compliant card charge from a single call transfer
- [Cards](https://docs.natural.com/guides/products/cards): Issue debit and charge cards for your agents the moment they're connected
- [Accept](https://docs.natural.com/guides/products/accept): Accept card payments by giving your agents merchant capabilities, all through API
